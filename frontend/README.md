# Smart Traffic Management System: Frontend

React + TypeScript + Vite dashboard for the Smart Traffic Management backend.

## Setup
```bash
npm install
```
Create `.env` in this folder:
```
VITE_API_URL=http://127.0.0.1:8000
```

## Run
Start the backend first, then:
```bash
npm run dev
```

## Pages
| Page | Content |
|---|---|
| Dashboard | Upload 4 images, summary cards, per-direction results |
| Junctions | Status card for each approach |
| Analytics | Vehicle and green-time charts for the latest analysis |
| Monitoring, Predictions | Future scope (video input, historical forecasting) |
